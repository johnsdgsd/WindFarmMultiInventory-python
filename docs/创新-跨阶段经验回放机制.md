下面给出一个可以写进论文方法节的完整算法描述。我把它命名为 **DG-CSER-SDDP：Diagnosis-Guided Cross-Stage Experience Replay for SDDP（诊断引导的跨阶段经验回放 SDDP）**。它由文献 BL-SDDP 的阶段内经验回放、你已有的 gap 分项/分阶段诊断、以及我们讨论的“同组跨阶段状态点共享”三部分组成。下面严格区分“沿用文献的部分”和“本文新增的部分”。

# DG-CSER-SDDP：诊断引导的跨阶段经验回放 SDDP

## 0. 定位与一句话概括

> 传统 SDDP 只围绕当前轮 trial points 建割；BL-SDDP 在阶段内回放历史 trial actions；本文先用仿真中的每期割欠估和成本项分解定位 gap 来源，再把参数 regime 相近的阶段划为组，在组内**只迁移目标阶段尚未覆盖、可行、且与 gap 来源成本项匹配的状态点**，在**目标阶段重新求解并重建割**，并配合 gap 阶段的 hybrid 割保留与多样性 batch 选择，以提升 LB、缩小 gap。

**不共享割，不共享动作，只共享经准入筛选和可行性修复的状态点。**

---

## 1. 动机：三个实验观察

DG-CSER 的设计直接来自你的实验数据，不是凭空加模块。

### 观察 1：gap 是结构化的，不是均匀分布

T60（2000 路径，128 轮 cuts）：

- gap = 112.47，UB=825.42，LB=712.95，gap=13.63%；
- 按未来成本分摊：采购 +77.65（69.0%），停机 +62.80（55.8%），持有 −21.80（−19.4%），主动/被动调拨为负；
- 按阶段：37–44、48、53 以采购欠估为主（占比 80%–86%）；54–55 以停机/被动/持有为主；第 60 期欠估为 0；第 1–6 期欠估 <1。

T240（1000 路径，377 轮 cuts）：

- gap 约 47,073，停机 82.7%，采购 16.9%，持有/调拨约 0；
- top 阶段约 162–194，中后期停机相关。

**含义**：不是所有阶段、所有成本项都值得加割。均匀回放或均匀加前向路径会浪费预算。

### 观察 2：割数 ≈ 唯一状态数

你已观察到 LML1 下每历史点只留最大割，割数大致等于唯一状态数。这意味着：

- 单纯增加轮数、重复回放相似 trial points，不会显著提升 LB；
- 真正缺的是**状态覆盖**，不是割的条数。

**含义**：经验回放必须解决“目标阶段没见过的状态”，而不只是“把旧点再算一遍”。

### 观察 3：阶段内回放有信息流，但没有覆盖扩展

BL-SDDP 的阶段内 replay 能在后向链中传播更新后的 \(Q_{t+1}\)，抑制后向误差传播；但它回放的是本阶段已访问过的经验，**不会给目标阶段带来新的状态区域**。

**含义**：需要一个“跨阶段但受控”的状态覆盖补充机制。

## 2. 问题设定与符号

沿用文献记号：

- 阶段 \(t=1,\dots,T\)；状态 \(s_t=(x_{t-1},\xi_t)\)；动作 \(a_t=(x_t,y_t)\)；
- 成本 \(C_t(s_t,a_t)=u_t^\top x_t+v_t^\top y_t\)；
- Q 因子 \(Q_t(s_t,a_t)=C_t(s_t,a_t)+\mathcal V_{t+1}(s_t,a_t)\)；
- 值函数近似 \(\mathcal V_t\) 由割集合 \(\mathcal H_t\) 表示，每个割 \(h=(\alpha_h,\beta_h)\)：
  \[
  \mathcal V_t(x)\approx \max_{h\in\mathcal H_t}\{\alpha_h+\beta_h^\top x\}.
  \]
- 前向路径数 \(N_f\)（你当前约 10）；replay 周期 \(Z\)；batch 大小 \(K\)；阶段组 \(\mathcal G=\{G_1,\dots,G_m\}\)。

新增符号：

- \(M_t\)：阶段 \(t\) 的本阶段经验池，元素为 \((s_t^n,a_t^n,s_{t+1}^n)\) 或至少 \((x_{t-1}^n,x_t^n,y_t^n)\)；
- \(C_t\)：阶段 \(t\) 的状态覆盖池，元素为状态 \(x_{t-1}\)（或 \(x_t\)，取决于你阶段状态的约定），用于最近邻判断；
- \(z(x)\)：阶段不变特征映射（见 §5）；
- \(d(x,C_t)=\min_{x'\in C_t}\|z(x)-z(x')\|_2\)：覆盖缺口度量；
- \(\tau_t\)：阶段 \(t\) 的覆盖缺口阈值；
- \(\ell_t\)：阶段 \(t\) 的 gap 来源成本项标签集合，如 \(\{\text{采购}\}\)、\(\{\text{停机},\text{被动}\}\)；
- \(w_t\)：阶段 \(t\) 的回放优先级权重；
- \(\delta_t\)：仿真中阶段 \(t\) 的平均割欠估：
  \[
  \delta_t=\mathbb E_{\text{paths}}\big[(C_t+\theta_t)-\theta_{t-1}\big].
  \]

**约定**：跨阶段迁移的是“进入某阶段的状态”部分。若你保存的是 \(x_t\)（第 \(t\) 期末库存），迁移到目标阶段 \(t'\) 时按目标阶段状态语义做时间平移解释，并做可行性修复；动作 \(y\) 和割系数 \(\alpha,\beta\) 一律不迁移。

## 3. 算法总览

DG-CSER-SDDP 在标准 SDDP 循环上增加四个组件：

1. **Gap 诊断**（每若干轮或每轮离线更新一次）：计算 \(\delta_t\)、成本项归因，得到 \(w_t\)、\(\ell_t\)；
2. **阶段分组**：按参数 regime 和 gap 来源把阶段划为组 \(\mathcal G\)；
3. **跨阶段覆盖缺口回放**：在组内选候选状态，做可行性修复、覆盖缺口筛选、成本项匹配、多样性筛选，准入目标阶段候选池；
4. **目标阶段重建割 + hybrid 割保留**：对候选状态在目标阶段重新求解建割；在 gap 阶段保留更多割，非 gap 阶段继续 LML1，并按 slack/年龄淘汰。

整体流程：

```
初始化割池、覆盖池、经验池
for iter = 1..N_max:
    1. 前向 pass：N_f 条路径，得到 trial actions，加入 M_t、C_t
    2. 后向 pass：标准 SDDP 更新，生成割，按 LML1/hybrid 管理
    3. if iter % Z == 0:
        3.1 诊断更新：δ_t、成本项归因、w_t、ℓ_t（可用最近仿真）
        3.2 阶段分组 G（初始化时定，可定期复核）
        3.3 跨阶段候选生成：
            for t = T..1:
                从 M_t 取本阶段 batch
                从同组 s≠t 的 M_s 取状态，修复、筛选、准入
                对合并 batch 在阶段 t 重新求解建割
                更新 H_t、C_t、Q_t
        3.4 割保留/淘汰
    4. 记录 LB、UB、gap、每阶段欠估、割数、唯一状态数、LP 数
until 达到 deadline / 目标 gap / 最大轮数
```

注意：文献 BL-SDDP 的 replay 是“逐阶段 \(T\to1\)，用更新后的 \(Q_{t+1}\) 重建本阶段割”。DG-CSER 保留这个后向顺序，只在每个阶段的 batch 里额外加入跨阶段准入状态。

## 4. 模块一：Gap 诊断

### 4.1 每期割欠估

对仿真路径 \(\omega\)，逐期计算：

\[
\delta_t(\omega)=\big(C_t(s_t,a_t)+\theta_t\big)-\theta_{t-1},
\]

其中 \(\theta_t\) 是前向/仿真中值函数近似给出的未来成本估计。平均得 \(\delta_t\)。你已验证这些欠估之和等于 UB−LB（在相应口径下）。

### 4.2 成本项归因

对每个阶段 \(t\)，把 \(\delta_t\) 按该期之后的未来成本结构分摊到采购/持有/停机/主动/被动五项，得到 \(\delta_{t,c}\)。这是归因，不是唯一答案，用于优先级。

### 4.3 生成回放权重与标签

- 阶段权重：
  \[
  w_t=\frac{\max(\delta_t,0)}{\sum_{t'}\max(\delta_{t'},0)}
  \]
  或分位数归一化；
- 成本项标签：
  \[
  \ell_t=\{c:\ \delta_{t,c}\ \text{占该阶段正欠估的主要部分}\}
  \]
  例如 T60 37–44 标“采购”，54–55 标“停机/被动/持有”；T240 162–194 标“停机”。

**默认用法**：

- T60：\(w_t\) 高在 37–44、48、53、54–55；第 60 期 \(w_{60}=0\)；第 1–6 期低权重；
- T240：\(w_t\) 高在 162–194（可扩展到 162–240）。

诊断是启发式优先级，不是收敛性证明；它只决定“先补哪里”，不保证每步都提升 LB。

## 5. 模块二：阶段分组

### 5.1 分组原则

同组应满足：

1. 状态变量维度和语义可平移；
2. 成本结构、容量/需求 regime、失效 regime 相近；
3. gap 来源成本项相近；
4. 末期效应不同者不混组（例如 T60 第 60 期排除）。

### 5.2 默认分组

基于你的数据：

- **T60**：
  \[
  G_1=\{37,\dots,44,48,53\}\quad(\text{采购主导}),
  \]
  \[
  G_2=\{54,55\}\quad(\text{停机/被动/持有}),
  \]
  第 60 期单列或不参与跨阶段；第 1–6 期低优先。
- **T240**：
  \[
  G=\{162,\dots,194\}\quad(\text{停机主导}),
  \]
  可扩展到 162–240；采购相关阶段可另设小组。

组间不共享。T60 与 T240 之间绝不共享。

### 5.3 定期复核

每若干轮（如 20 轮）用最新 \(\delta_t\) 复核分组；若某阶段欠估主导项变化，可调整标签，但组划分不宜频繁变动，避免实验不可复现。

## 6. 模块三：特征空间与覆盖缺口

### 6.1 特征映射 \(z(x)\)

跨阶段比较不能用时间索引，要用阶段不变/可平移特征：

\[
z(x)=\Big[
x_n/\bar X_n,\ 
\text{Qmax 贴边比例},\ 
\text{Imax 贴边比例},\ 
\text{失效比例},\ 
\text{需求/容量比},\ 
\text{调拨压力指标}
\Big].
\]

建议附加离散标签（不进距离，做硬筛选）：采购主导/停机主导/调拨主导；阶段组内相对位置（谨慎使用）。

不可平移状态（年龄、提前期、失效 regime 计数）要么不共享，要么只在完全同构阶段间共享。

### 6.2 覆盖池 \(C_t\)

阶段 \(t\) 维护已有状态的特征集合。每次前向或 replay 准入后更新。为控制规模，可用：

- 随机子采样保留 \(C_t\) 上限（如 2000–5000 点）；
- KD-tree / 近似最近邻；
- 或聚类中心 + 半径。

### 6.3 覆盖缺口

候选 \(x\) 对目标阶段 \(t\) 的覆盖缺口：

\[
d(x,C_t)=\min_{x'\in C_t}\|z(x)-z(x')\|_2.
\]

准入条件之一：\(d(x,C_t)>\tau_t\)。\(\tau_t\) 可取目标阶段已有最近邻距离的 80% 分位，或固定分位数；不同阶段可不同。

---

## 7. 模块四：跨阶段候选准入

对目标阶段 \(t\)，同组源阶段 \(s\in G(t),s\ne t\)，候选状态 \(x_s\in M_s\)。准入需同时满足：

1. **语义/维度一致**：可时间平移解释；
2. **可行性修复**：投影/修复到阶段 \(t\) 可行域，得到 \(x_s^{\text{rep}}\)；修复后仍不可行则丢弃；
3. **覆盖缺口**：\(d(x_s^{\text{rep}},C_t)>\tau_t\)；
4. **成本项匹配**：源状态标签与 \(\ell_t\) 有交集；例如 T60 采购组只收采购主导状态，54–55 收停机/被动主导；
5. **非冗余**：与本次 batch 已选状态的特征距离大于 \(\epsilon\)（多样性）；
6. **batch 上限**：每阶段跨阶段准入数量不超过 \(K_{\text{cross}}\)，总 batch 不超过 \(K\)。

形式化：

\[
\mathcal A_t=\Big\{x_s^{\text{rep}}:\ s\in G(t),s\ne t,\ x_s\in M_s,\ 
\text{feasible}_t(x_s^{\text{rep}}),\ 
d(x_s^{\text{rep}},C_t)>\tau_t,\ 
\ell(x_s)\cap\ell_t\ne\varnothing,\ 
\text{diverse}\Big\}.
\]

**关键**：只迁移状态，不迁移动作 \(a_s\)，不迁移割。目标阶段重新优化动作。

---

## 8. 模块五：目标阶段重建割

对阶段 \(t\) 的 replay batch：

\[
B_t=B_t^{\text{local}}\cup B_t^{\text{cross}},
\]

其中 \(B_t^{\text{local}}\subset M_t\) 是本阶段经验（BL-SDDP 部分），\(B_t^{\text{cross}}\subset\mathcal A_t\) 是跨阶段准入状态。

对每个 \(x\in B_t\)：

1. 在阶段 \(t\) 子问题中求解：
   \[
   \min_{a_t\in\mathcal A_t(s_t)} C_t(s_t,a_t)+\mathcal V_{t+1}(s_t,a_t),
   \]
   其中 \(\mathcal V_{t+1}\) 使用本次 replay 中已更新的 \(Q_{t+1}\)；
2. 取对偶/次梯度 \((\alpha,\beta)\)；
3. 生成阶段 \(t\) 割：
   \[
   \theta_t\ge \alpha+\beta^\top x;
   \]
4. 加入 \(\mathcal H_t\)；
5. 更新 \(C_t\)。

后向顺序仍为 \(t=T,\dots,1\)，保证 \(Q_{t+1}\) 先更新。跨阶段状态只改变“在哪些点建割”，不改变建割规则。

## 9. 模块六：割保留与淘汰（Hybrid LML1）

### 9.1 分阶段策略

- **高欠估阶段**（T60 37–55；T240 162–240）：关闭或放松 LML1，保留更多割；或对每个历史点保留 top-\(k\) 割（如 \(k=2,3\)）；
- **低欠估阶段**：继续 LML1，每历史点留最大割；
- **第 60 期**（T60）欠估为 0：不额外加割；
- **持有/调拨主导阶段**：不优先加割，它们多为负贡献。

### 9.2 淘汰规则

对保留的割按：

- slack 大小：删除 slack 大的老割（你提到 T240 有 slack 达 2508 的老割）；
- 年龄：超过若干轮未被激活的割；
- 冗余度：与现有割法向接近且不提升 LB 的割；

淘汰以控制 LP 规模，腾出时间给 replay。

### 9.3 与跨阶段回放的配合

跨阶段准入可能产生弱割/冗余割，因此必须：

- 每阶段跨阶段准入有上限 \(K_{\text{cross}}\)；
- 新割加入后检查该阶段欠估和 LB 是否改善；
- 连续若干轮无改善的跨阶段割优先淘汰。

## 10. 模块七：Batch 选择与多样性

文献比较了 full/random/best/worst batch。DG-CSER 的 batch 选择建议：

\[
\text{priority}(x)=\alpha_1\frac{\hat\delta_t(x)}{\max\hat\delta}
+\alpha_2\,\mathbb 1[\ell(x)\cap\ell_t\ne\varnothing]
+\alpha_3\,\text{novelty}(x,C_t)
-\alpha_4\,\text{sim}(x,B_t^{\text{selected}}).
\]

其中：

- \(\hat\delta_t(x)\)：该状态/路径在仿真中的欠估贡献；
- \(\text{novelty}=d(x,C_t)\) 归一化；
- \(\text{sim}\)：与已选状态的相似度，做多样性。

默认：

- \(B_t^{\text{local}}\)：按 \(w_t\) 采样，最多 \(K_{\text{local}}\)；
- \(B_t^{\text{cross}}\)：按上式排序，最多 \(K_{\text{cross}}\)；
- 总数 \(K=K_{\text{local}}+K_{\text{cross}}\) 控制单轮 replay 成本。

T240 单轮约 138 s，full-batch 不可承受；建议 mini-batch，且只在高 \(w_t\) 阶段做跨阶段回放。T60 单轮约 28 s，可先试 full-batch 和较大 \(K\)。

## 11. 完整伪代码

```text
输入：阶段数 T，前向路径 N_f，replay 周期 Z，batch 上限 K，
      跨阶段上限 K_cross，阶段分组 G，特征 z，阈值 τ_t，标签 ℓ_t
初始化：割池 H_t，覆盖池 C_t，经验池 M_t，Q_t 初值

for iter = 1..N_max:
    # 1. 标准 SDDP 前向
    for ω in 1..N_f:
        从 s_1 前向，得到每阶段 trial (s_t,a_t,s_{t+1})
        加入 M_t；更新 C_t

    # 2. 标准 SDDP 后向
    for t = T..1:
        围绕本阶段 trial points 建割，加入 H_t
        按 LML1/hybrid 管理 H_t

    # 3. 周期 replay
    if iter % Z == 0:
        # 3.1 诊断
        用最近仿真计算 δ_t、成本项归因、w_t、ℓ_t
        # 3.2 分组（初始化时定，定期复核）
        # 3.3 跨阶段 + 阶段内 replay
        for t = T..1:
            B_local = 从 M_t 按 w_t 采样，最多 K_local
            B_cross = []
            for s in G(t), s != t:
                for x_s in M_s:
                    x_rep = repair_to_stage_t(x_s)
                    if feasible_t(x_rep)
                       and d(z(x_rep), C_t) > τ_t
                       and ℓ(x_s) ∩ ℓ_t != ∅
                       and diverse(x_rep, B_cross):
                        B_cross.append(x_rep)
                        if len(B_cross) >= K_cross: break
            B = B_local ∪ B_cross
            for x in B:
                在阶段 t 子问题中求解，用当前 Q_{t+1}
                得到 (α,β)，生成割，加入 H_t
                更新 C_t
            # 3.4 割保留/淘汰
            高欠估阶段保留更多割；低欠估阶段 LML1
            按 slack/年龄/冗余淘汰

    # 4. 记录
    LB, UB, gap, δ_t, 割数, 唯一状态数, LP 数, 单轮时间
    若达到 deadline/目标 gap，终止
```

## 12. 理论性质

### 12.1 割的有效性

对凸分段线性值函数，围绕**目标阶段可行状态**求解子问题得到的 Benders 割，是该阶段值函数的有效下界支持超平面。因此：

> 跨阶段状态只要修复后在目标阶段可行，在目标阶段重新求解生成的割是有效下界割，不会破坏 LB 有效性。

这要求：

- 不复制割；
- 不复制动作；
- 状态修复后确实满足目标阶段约束；
- 随机实现使用目标阶段自己的分布。

### 12.2 不保证每步提升

跨阶段状态可能产生弱割或冗余割。算法只保证割有效，不保证每步 LB 单调提升更快。因此需要：

- 准入筛选（覆盖缺口 + 成本项匹配 + 多样性）；
- batch 上限；
- 割淘汰；
- 实验验证。

### 12.3 与 BL-SDDP 的关系

- BL-SDDP 是 \(K_{\text{cross}}=0\) 的特例；
- 传统 SDDP 是 \(Z=\infty\)（不做 replay）的特例；
- DG-CSER 通过 \(K_{\text{cross}}>0\) 和诊断驱动选择扩展状态覆盖。

## 13. 计算复杂度与并行

单次 replay 成本：

- 本阶段 batch：\(K_{\text{local}}\) 次目标阶段子问题；
- 跨阶段 batch：\(K_{\text{cross}}\) 次目标阶段子问题；
- 准入筛选：\(O(|M_s|\cdot d\cdot |C_t|)\) 最近邻，可用 KD-tree/近似；
- 总 replay 成本约 \((K_{\text{local}}+K_{\text{cross}})\times T\) 次子问题，乘以 replay 次数。

并行：

- 文献 BL-SDDP 的 batch 可分配到多 CPU，阶段末同步共享割；
- DG-CSER 同样可并行：\(B_t\) 中每个状态独立求解子问题，跨阶段准入筛选也可并行；
- T240 单轮 138 s，建议 mini-batch + 只在高 \(w_t\) 阶段 replay；T60 单轮 28 s，可先全量验证。

内存：

- \(M_t\)、\(C_t\) 需要上限和子采样；
- 跨阶段候选不要全量扫描，可按标签/阶段组预筛。

## 14. 与 SDDP、BL-SDDP 的区别

| 维度 | 传统 SDDP | BL-SDDP | DG-CSER-SDDP |
|---|---|---|---|
| 回放范围 | 无 | 本阶段历史经验 | 本阶段 + 同组跨阶段准入状态 |
| 选择依据 | 当前 trial points | full/random/best/worst | 诊断权重 + 覆盖缺口 + 成本项 + 多样性 |
| 共享内容 | — | 本阶段 trial actions | 只共享状态点；不共享动作/割 |
| 建割位置 | 当前 trial points | 本阶段历史点 | 本阶段历史点 + 跨阶段修复状态 |
| 割保留 | 通常全留或 LML | 同 SDDP | gap 阶段 hybrid，非 gap 阶段 LML1 |
| 目标 | 收敛 | 抑制后向误差、提升 LB | 同时补状态覆盖 + 抑制后向误差 + 聚焦 gap 来源 |
| 诊断 | 无 | 无 | 每期欠估 + 成本项归因 |

## 15. 默认超参数建议

基于你的数据：

- \(N_f\)：T60 可先 10，再试 20/40；T240 保持 10 或适度增加，注意单轮时间；
- \(Z\)：5 或 10；
- \(K_{\text{local}}\)：T60 可 20–50；T240 10–20；
- \(K_{\text{cross}}\)：T60 10–30；T240 5–15；
- \(\tau_t\)：目标阶段已有最近邻距离的 80% 分位；
- 阶段组：
  - T60：\(G_1=\{37–44,48,53\}\)，\(G_2=\{54,55\}\)，第 60 期排除；
  - T240：\(G=\{162–194\}\)，可扩到 162–240；
- 成本项标签：T60 \(G_1\) 采购，\(G_2\) 停机/被动/持有；T240 停机；
- hybrid 割保留：T60 37–55 保留 top-2/3；T240 162–240 保留 top-2/3；其他 LML1；
- 淘汰：slack 大于阶段分位 90% 且连续 5 轮未激活的割优先删。

这些是起点，需在 T60 上做敏感性。

## 16. 实验设计与消融

先在 T60（1 小时预算）做 A/B，再在 T240 验证。

### 16.1 对照组

1. baseline SDDP；
2. BL-SDDP 阶段内 replay（复现文献）；
3. 跨阶段随机共享（证明不是随便共享就行）；
4. 相邻阶段共享；
5. 同组全部共享（不加覆盖缺口筛选）；
6. 同组 + 覆盖缺口筛选；
7. 同组 + 覆盖缺口 + 成本项匹配（DG-CSER）；
8. DG-CSER + hybrid 割保留；
9. DG-CSER + hybrid + 多样性 batch。

### 16.2 指标

- 固定墙钟时间 LB、UB、gap；
- 达到目标 gap 的时间；
- 高欠估阶段（T60 37–55；T240 162–240）的 LB 改善和 \(\delta_t\) 下降；
- 每阶段唯一状态数、割数；
- LP 求解次数、单轮时间；
- 跨阶段新割的 LB 提升率、冗余割比例、淘汰率；
- out-of-sample UB（2000/10000 路径）；
- 并行效率（若多 CPU）。

### 16.3 预期

- 随机/相邻跨阶段可能无改善甚至变差，证明准入筛选必要；
- 覆盖缺口 + 成本项匹配应改善 T60 37–44、48、53 的采购欠估和 54–55 停机欠估；
- T240 应改善 162–194 停机欠估；
- hybrid 割保留应降低高欠估阶段 \(\delta_t\)，但需控制 LP 规模；
- 组合方法应在相同墙钟下得到更小 gap，或达到目标 gap 更快。

### 16.4 边界

- T60 是 5 年、低失效、容量宽松，不能外推 T240 的 20 年 10% 失效率；
- T240 以 resume 最终 377 轮结果为准；
- 两次训练都是 deadline/手动终止，不是自然收敛；
- 所有对比应在相同预算（墙钟或 LP 数）下进行。

## 17. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 跨阶段弱割/冗余割 | 覆盖缺口 + 成本项 + 多样性筛选；batch 上限；淘汰 |
| 阶段组划错导致分布偏移 | 按 regime 和 gap 来源分组；定期复核；消融相邻/随机对照 |
| 不可平移状态被误共享 | 只共享可平移特征；年龄/提前期/失效 regime 不跨组 |
| LP 规模膨胀 | hybrid 只在高欠估阶段；淘汰 slack 大/老割；子采样 \(C_t\) |
| 诊断噪声 | 用多路径平均；诊断只做优先级，不做收敛证明 |
| T240 预算不足 | mini-batch；只在高 \(w_t\) 阶段 replay；并行 |
| 实验不可复现 | 固定随机种子、分组、阈值；记录每轮诊断和准入统计 |

## 18. 论文贡献表述建议

1. 提出一种基于仿真割欠估和成本项分解的 **SDDP gap 诊断方法**，将 UB−LB gap 归因到阶段和成本项，识别 T60 采购/停机、T240 停机等主要来源；
2. 提出 **DG-CSER-SDDP**：在同 regime 阶段组内选择性迁移状态点，仅准入目标阶段覆盖不足、可行、且与 gap 成本项匹配的状态，在目标阶段重新求解建割，不共享割和动作；
3. 结合 **hybrid 割保留** 和 **多样性 batch 选择**，在控制 LP 规模的同时补状态覆盖；
4. 在 T60/T240 上做系统消融，验证相对 SDDP、BL-SDDP、随机/相邻跨阶段共享的 LB-gap-time 改善；
5. 给出长视界下经验回放、状态覆盖与割选择之间关系的实验分析，并明确 T60 不外推 T240 的边界。

## 19. 一句话总结

**DG-CSER-SDDP 不是“把别的阶段的割拿过来”，而是“用 gap 诊断找到目标阶段缺什么状态，在同 regime 阶段组内只迁移目标阶段未覆盖、可行、与 gap 成本项匹配的状态点，在目标阶段重新建割，并在高欠估阶段保留更多割”。**
它把文献 BL-SDDP 的阶段内回放、你的 gap 分解诊断、以及跨阶段覆盖补充分工成一个闭环；理论合法性来自“目标阶段可行状态上的 Benders 割仍是有效下界割”，工程可控性来自准入筛选、batch 上限和割淘汰。
