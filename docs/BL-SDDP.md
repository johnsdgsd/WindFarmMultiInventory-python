## 一、摘要与核心贡献

针对多阶段随机规划的主流算法 SDDP，本文提出一种借鉴强化学习（RL）中 **经验回放（experience replay）/ 批学习（batch learning）** 的变体 —— **Batch Learning SDDP（BL-SDDP）**。要点如下：

- 将多阶段随机线性规划（MSLP）建模为马尔可夫决策过程（MDP），并证明 SDDP 本身是一种强化学习算法（Q-learning 式的双 pass 算法）。
- BL-SDDP 在后向 pass 中使用经验回放：把前向 pass 产生的试射点（trial actions）存入回放记忆，每隔 Z 次迭代对一批 K 个历史试射点重新构建割，以更准确地反向传播价值函数信息。
- 与 PSR 商业版 SDDP 对标，采用哥伦比亚互联水电厂长期规划的**大规模实例**，验证 BL-SDDP 能在更短时间内得到更紧的 gap。
- 提出 BL-SDDP 的并行策略，证明其比标准 SDDP 更适合并行计算、对算力增加的响应更友好。
- 在风险中性（risk-neutral）与风险厌恶（risk-averse，CVaR/AV@R）两种设定下均验证了优越性。

**四大贡献**：(i) 提出 BL-SDDP 并建立其与 RL 的联系；(ii) 对标 PSR 商业 SDDP；(iii) 展示其并行适用性；(iv) 在风险中性/厌恶设定下测试。

## 二、研究动机

### 2.1 SDDP 的挑战
- SDDP 可扩展地求解多阶段随机规划，理论上可有限步收敛，但**经验上常因计算限制无法收敛**。
- 例如巴西电力系统长期规划知名实例中，报告的 gap 高达约 **22%**（Shapiro et al., 2013）。
- 已有加速手段：割选择（去除冗余超平面）、正则化（选择更好的前向试射点）、利用问题结构的前向采样、并行计算等。但这些方法**从未与独立基准做过对比**。

### 2.2 并行计算的局限
- 文献中并行 SDDP 大多聚焦于**增加前向蒙特卡洛采样数量并分发到各处理器**。
- 但这种做法有副作用：并行前向越多，产生的试射点越相似，**累积冗余割**，反而不改善近似、严重拖慢收敛。
- 结论：**前向探索不足以保证可并行化，焦点应放在后向 pass 上**——后向 pass 是否足够准确才是关键。

### 2.3 批学习（Batch Learning）的引入
- RL 区分 model-free 与 model-based；随机规划提供了环境的模型，故聚焦 **model-based** 方法。
- 常规 RL 是"逐条更新"策略，而**批学习**延迟并批量更新，可避免昂贵矩阵乘、降低噪声，往往优于在线更新。
- **经验回放**是批学习的一种：重新采样历史迭代访问过的状态-动作对，用新信息替换旧信念，从而**缩短重新访问已探索状态的时间**（DeepMind 的 Atari 即用 Q-learning + 经验回放）。

## 三、问题建模：SDDP 与强化学习的桥梁

### 3.1 MDP 基本定义
MDP 由元组 (S_t, A_t, C_t, P) 定义：状态集、动作集、奖励函数、转移概率。目标是找策略 π ∈ Π 最小化期望成本 `min E[Σ C_t(s_t^π, a_t^π)]`。

### 3.2 多阶段随机规划 ↔ MDP（Lemma 2.1）
以两阶段水火电调度为例，将 MSLP（MSP-P）转化为 MDP：

- **状态**：`S_1 = {(x0, ξ1)}`，`S_t = {(x_{t-1}, ξ_t)}`；
- **动作**：`A_t(s_t) = F_feas(x_{t-1}, ξ_t)`，即满足约束 `B_t x_{t-1} + A_t x_t + D_t y_t = b_t` 的 (x_t, y_t)；
- **奖励**：`C_t(s_t, a_t) = u_t^T x_t + v_t^T y_t`；
- **转移**：`P(s_{t+1}|s_t,a_t) = P(ξ_{t+1}|ξ_t)`（数据过程为 Markov 链）。

**Lemma 2.2**：MDP-P 与 MSP-P 等价（每一 MSP 顶点解对应一个 MDP 策略，成本相同；反之亦然）。因线性规划的顶点解，可限制在有限动作集上。

### 3.3 SDDP 是强化学习算法（Lemma 2.3）
- 定义 Q 因子 `Q_t^π(s_t,a_t) = C_t(s_t,a_t) + V_{t+1}^π(s_t,a_t)`。
- SDDP 通过支撑超平面（割）在试射点 x_t^n 附近逼近 `V_{t+1}^*`，再经 Bellman 最优方程更新 Q 因子，与 Q-learning 结构一致（model-based 双 pass 算法）。
- 因此可直接借用 RL 中的成熟技术（如经验回放）。

## 四、BL-SDDP 算法

### 4.1 经验回放（Experience Replay）
- 动机：更新某状态-动作对 (s_t, a_t) 会影响前置状态 s_{t-1}，但该信息**只有重新访问 s_{t-1} 才会反向传播**，前置状态更需再次访问。经验回放可加速这种信息回传。
- 更新规则：`Q_t = U_t(s_t, a_t, s_{t+1}, Q_{t+1})`。
- 当 K 等于全部经验 → **full-batch**；K 小于全部 → **mini-batch**。

### 4.2 BL-SDDP 描述（Algorithm 3）
- 由于更新规则基于支撑超平面，回放记忆只需存**动作**：`M = {a_t^n : n = 1,…,N}`（不需要状态、奖励）。
- 流程：
  1. 执行通常 SDDP，收集最多 Z 个新试射点（动作），加入回放记忆 M；
  2. 从 M 中取一批 K 个经验，对其应用经验回放（每 K 个试射点批量更新割）。
- 效果等价于"每 Z 次 SDDP 迭代，批量更新 K 条割"。
- 可与其它前向采样方案（如 Donohue & Birge 2006、Hindsberger & Philpott 2014）组合，不冲突。

**性能提升机理**：BL-SDDP 在后向 pass 更勤奋地逼近价值函数，**防止后阶段价值函数近似误差"污染"前阶段近似**（抑制后向误差传播）。代价是每个后向 pass 计算量增加——用并行计算来弥补。

**流程（图1）**：常规 SDDP 迭代收集试射点 → 加入回放记忆 → 累积 Z 个后，取一批 K 个 → 围绕这批试射点构建割 → 割作为输入给 SDDP。

## 五、并行化策略

### 5.1 标准 SDDP 并行化
- 前向：N 个蒙特卡洛样本分发给各处理器；后向：把前向得到的试射点分发。
- 每阶段后向结束有同步点，割在处理器间共享。
- 文献变体：同步松弛（[19]）、异步（[30]）、按阶段分配处理器（[20]）——但性能依赖问题且不稳定。

### 5.2 BL-SDDP 的并行化（图3、图4）
- **SDDP 部分**：为避免冗余，前向**固定少量样本**，后向把每阶段的所有节点问题分发给处理器（例如 2 样本 × 3 节点/阶段 = 6 个问题，分布在处理器上），每阶段同步、建割、共享。
- **BL 部分**：从回放记忆 M_t 中选一批 K 个经验（试射点），分发给处理器；各处理器围绕收到的经验构建支撑超平面；每阶段结束同步以共享割。
- **可扩展性好**：增加处理器 → 每个处理器处理更少的经验，天然扩展。

## 六、实验（Case Studies）

### 6.1 测试实例
- **哥伦比亚水电系统**（PSR 提供）：32 个火电机组、42 个水电机组（25 个有库容）、54 维来水向量、无输电网。10 年、月度步长 → **120 阶段**；PAR(1) 来水模型（历史 1937–2019 校准）；每阶段 100 个不确定性实现（节点）。
- **巴西电力系统**（含输电网，[16] 实例）：4 个等价能源水库、运输网模型、120 阶段、100 实现/阶段；两种不确定性建模（时间序列法 / Markov 链法）。
- **泛欧 ERAA 模型**：56 区域、109 条线路、一年视界、92 阶段（每阶段 4 天）、35 节点/阶段。

**实现**：Julia 0.6 + JuMP 0.18，LP 求解器 Gurobi 8（自研）；PSR SDDP 用 FORTRAN + XPRESS。

### 6.2 关键对比结论（哥伦比亚）
- **与 PSR SDDP 对比（单 CPU，34 小时）**：
  - 每迭代 20 前向样本；每 5 迭代做一次 full-batch 更新；批量=全部经验。
  - BL-SDDP 在同样参数下，34 小时后得到**更紧的 gap**，且 out-of-sample（2000 个来水样本）表现更优。
  - 尽管自研 SDDP 比 PSR 慢约 6 倍（20 迭代：PSR 约 30 分钟 vs 自研约 3 小时），BL-SDDP 仍靠**更少的工作量**取胜：
    - PSR 370 迭代共解 **88,060,000** 个 LP；
    - BL-SDDP 25 常规迭代 + full-batch 更新共约 **23,800,000** 个 LP，**仅为 PSR 的 27%**；
    - 每阶段割数：PSR ≈ 7,400 条 vs BL-SDDP ≈ 500 条（更轻的近似）。
  - 机理：BL-SDDP **避免过度探索**，从而避免冗余计算。
- **并行对比（20 CPU）**：BL-SDDP 全程 gap 显著更紧；算力增加时 BL-SDDP 改善更明显；两算法并行效率均约 0.8。

### 6.3 价值函数对比（图9）
- 在 SDDP 的试射点处比较 BL-SDDP 与 SDDP 的期望价值函数近似。
- 结果：几乎全部阶段相对差为正（BL-SDDP 割更紧）；越靠前的阶段差异越大（因为 SDDP 的后向误差传播）。仅最末阶段为负（约 −20%），符合预期——末阶段 SDDP 在自身试射点处本就紧。

### 6.4 批次选择规则（图10）
四种规则（批次占 50%，F 除外）：
- **F**：full-batch（全部经验）；
- **R**：random（随机批）；
- **B**：best cuts（选 δ_i = V(x_i) − C_i(x_i) 最小的割，即最紧的）；
- **W**：worst cuts（选 δ_i 最大的割，即最差的）。

结论：**W 和 R 表现最差；B 在早期显著优于 F；长期 B 与 F 表现相近**。更多批次策略留作未来工作。

### 6.5 风险厌恶设定（图11）
- 风险测度 `ρ_t[Z] = (1−λ)E_t[Z] + λ·AV@R_α[Z]`（AV@R = CVaR）。
- 不同 λ∈[0,1] 下，**BL-SDDP 的下界一致优于标准 SDDP**。

### 6.6 巴西与泛欧验证
- 巴西含输电网：时间序列法与 Markov 链法下，BL-SDDP 均显著优于 SDDP；时间序列法收敛更慢（与 [5] 一致）。
- 泛欧 ERAA（一年经济调度，56 区域/109 线路）：6 小时后 **BL-SDDP gap ≈ 5%**，标准 SDDP **gap ≈ 100%**——结论推广到更复杂拓扑。

---

## 七、结论

- 提出融入 RL 思想的 SDDP 变体 BL-SDDP，在含挑战性的电力系统问题上优于商业级 SDDP 实现。
- 开启"SDDP 可否受益于其它 RL 技术（尤其是**经验选择策略**）"的探索方向。
- BL-SDDP 受益于并行计算更多，但**仍需同步**，仍受已知同步问题的制约。

## 八、对你的课题（备件库存/跨阶段经验回放）的可借鉴点

1. **回放记忆只需存"动作/试射点"而非完整状态-动作-奖励三元组**——这是 BL-SDDP 的关键简化，得益于基于支撑超平面的更新规则。
2. **BL-SDDP 严格"本阶段内回放"**：M_t 只含本阶段 t 的历史试射点，不做跨阶段共享。这与你的 CG-CSER（阶段组内跨阶段共享状态点）形成**直接差异化**——你的想法正是在此基础上的推广。
3. **"最紧割优先"（B 规则）的批选择**与你的"gap 来源成本项匹配/覆盖缺口筛选"在理念上呼应，但 B 规则仅按当前割紧度选，不考虑目标阶段的覆盖缺口与欠估标签。
4. **并行扩展性论证范式**（固定前向小样本 + 后向批量分发）可迁移到你的跨阶段重放实验设计中。
5. **对标基准**：BL-SDDP 用 PSR 商业软件 + 自研双实现做对比，值得你的 A/B 消融实验借鉴（baseline / BL-SDDP 复现 / 跨阶段随机共享 / 覆盖缺口筛选 / +hybrid 割保留）。
