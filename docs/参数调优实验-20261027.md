3. **收敛速度和 gap 不恶化，最好略有改善**；

## 3. 参数影响力排序与机制

### 3.1 Cs（停机单价）——影响最大，但方向不对

G1 → G2（Cs 20→60）：

- 停机占比 34.9% → **44.3%**，\( \bar W \) 1.35 → 0.79，库存 4.57 → 5.03，贴 Qmax 31.1% → 37.2%；
- 但**被动调拨从 4.1% 涨到 8.8%**，采购从 56.3% 降到 43.2%，**采购+停机反而从 91.2% 降到 87.6%**；
- 同预算 gap 22.9% → 28.4%（成本尺度也变了，但 LB 轨迹显示相对收敛并未变快）。

**机制**：Cs 升高 → 模型更努力避免停机（多备货、多调拨）；停机量下降，但停机单价上升，同时调拨成本被拉起来。**"停机占比"和"采购+停机占比"不是一回事**：前者可以靠 Cs 拉高，后者会被调拨挤下去。

### 3.2 Qmax（产能）——提"采购+停机"和"停机"的最有效杠杆，但 gap 变差

G1 → G3（Σ13→9）：

- 停机占比 34.9% → **50.7%**，\( \bar W \) 1.35 → 2.43，贴 Qmax 31.1% → **51.0%**，利用率 55.3% → 74.6%；
- 采购+停机 91.2% → **93.2%**，持有 1.4% → 0.9%，调拨 7.4% → 6.0%；
- 同预算 gap 22.9% → 25.3%（同成本，直接可比）。

**代价**：G3 的产能 108 台/年 < 第 5 年需求 128 台/年，待修队列从第 1–12 期的 7.7 台涨到后 12 期的 **44.9 台**（第 60 期 73.1 台）。这是**结构性缺口**，不是末期效应；内区（5–57 期）停机占比仍有 47.9%。

G4（Σ10）是中间档：停机 46.6%、P+D 92.5%，但 gap **28.9%**，比 G3 更差。说明"中等稀缺"的策略在"订/不订、调拨/等待"之间切换，值函数更复杂，割更难逼近；反而 G3 的极度稀缺让策略退化成"尽量订满 + 等"，值函数更简单。

### 3.3 atc / tc（调拨成本）——提高后反而更差

G1 → G5（15/20 → 30/40）：

- 调拨量下降，但**调拨成本占比从 7.4% 升到 9.1%**（单位成本翻倍，量降得不够）；
- \( \bar W \) 1.35 → 1.77，停机 34.9% → 40.6%，采购 56.3% → 49.1%，**P+D 91.2% → 89.7%**；
- 同预算 gap 22.9% → **29.1%**。

**机制**：调拨贵 → 模型更多选择等待 → 停机上升；同时"等待 vs 调拨"的权衡更复杂，值函数更难逼近。**不建议把提高 atc/tc 当作提 P+D 或改善 gap 的手段**；它更适合作为现实性参数，且 15/20 已经偏贵，5/10 更利于收敛。

### 3.4 h（持有成本）——只影响持有占比，几乎不影响 gap

G1（h=0.4）→ G7（h=1.0）：

- 持有占比 1.4% → 3.3%，其余占比变化 1–2 pp；
- 同预算 gap 22.87% → **22.67%**（−0.20 pp，噪声级）。

**结论**：降低 h 是"免费"的——它把持有成本占比直接压下去，不恶化 gap。**G8 就是利用这一点**：保持调拨成本 5/10，只把 h 降到 0.4，于是 gap 回到 14.12%（甚至略好于 R00），同时持有降到 1.76%。

### 3.5 I0（初始库存）——只去瞬态，不影响 gap

G1（I0=1 月）→ G6（I0=0）：

- 第一期成本 461.8 → 608.7，前 12 期总成本约高 8%；
- 同预算 gap 22.87% → 23.27%（+0.40 pp）。

**结论**：I0 的价值是让 5 年窗口不从"空库存 + 已有失效"的假瞬态开始；对收敛/gap 没有实质帮助。推荐保留 1 个月，便于策略分析时不用剔除前几期。

### 3.6 初始机队分布

本次所有组都用 127 月龄（≈99 台/年），与 T240 同一条 20 年轨迹一致。未单独扫描 110/140 月；若需要更高的失效率，可把 `init_mix` 换成 140 月龄（≈115 台/年），但失效量本身不改变成本占比（每多一台失效，采购和停机同比例放大），主要影响绝对成本与状态多样性。

## 4. 三条路线与取舍

| 路线 | 代表 | gap | 采购+停机 | 停机 | 持有 | 适用 |
|---|---|---:|---:|---:|---:|---|
| **gap 优先** | R00（旧成本）| **14.68%** | 90.46% | 28.51% | 3.78% | 算法 A/B、需要最佳收敛 |
| **推荐折中** | **G8** | **14.12–14.49%** | **92.08–92.09%** | 26.79–27.05% | **1.74–1.76%** | 论文主结果：成本结构合理 + gap 不差 |
| **停机主导** | F2（G3）| 22.42% | **92.96%** | **49.49%** | **0.91%** | 强调停机/产能约束，需接受积压与 gap |

**核心结论：在本模型上，"停机+采购占绝大部分（>93%）"和"gap 更小"不可兼得。** 让停机占比接近 50% 需要产能结构性缺口（Qmax Σ=9），这会让值函数更复杂、相对 gap 变大（14.7% → 22.4%），并造成末期积压增长。要两者兼得，必须回到割的表示/算法层面，而不是继续调成本参数——这与之前 BL-SDDP、DG-CSER、去重等创新只到约 0.4 pp 的结论一致。

## 6. 限制与待办

1. **单次运行噪声**：LP 对偶退化 + 多进程 ⇒ 同参数不逐位复现；gap 差异 <0.5 pp 不建议当结论。G8 两次运行 gap 14.12% / 14.49%（均值 14.30%），比 R00 的 14.68% 低约 0.4 pp，属于"不恶化、可能略好"，不宜宣称显著改进；但成本结构非常稳定（采购+停机 92.08% / 92.09%，持有 1.76% / 1.74%），这部分结论是稳的。
2. **gap 与成本尺度**：Cs 或调拨成本改变会同时改变真实最优值和策略误差成本，跨组的相对 gap 只能做方向性比较；G8 与 R00 的成本尺度最接近，比较最干净。
3. **末期积压**：F2/G3 的第 5 年需求（128 台/年）> 产能（108 台/年），积压持续增长；若论文用 5 年窗口，需要说明这是压力场景，或改用 Qmax Σ=10/11 并接受较低的停机占比。
4. **T240 未验证**：所有结论来自 T60。T240 的 20 年窗口、末期峰值 16.5 台/月与产能 13 台/月的关系不同，G8 的 h/I0 改动是否能迁移，需要一次 T240 长跑验证（约 11 h）。
5. **`max_train_seconds` 与 `I0` 是实验分支功能**：若要把 G8 作为正式基线，建议先把这两个功能整理成独立提交（仍在 `exp-param-tune`，不合入 main），或在正式配置里显式写 `max_train_seconds = 0` 并改用外部停止。
6. **`init_mix=127 月` 的论文口径**：T60 不再是"质保期前 5 年"，而是同一机队第 11–15 年窗口；正文必须写明，否则与"20 年累计 8.8%"的叙述会打架。
