# LML1 割筛选算法实现逻辑

## 1. 背景与符号定义

在多阶段随机线性规划的 SDDP / MuDA 算法中，每轮迭代会为每个阶段 \(t\)、每个场景节点 \(j\) 生成新的最优性割（optimality cut），用于下近似未来成本函数 \(\Omega_t(\cdot, \xi_{tj})\)。

随着迭代进行，割的数量线性增长，导致子问题规模膨胀。**LML1（Limited Memory Level 1）** 是一种割筛选策略：在求解前向/后向子问题时，只使用一部分“最有用”的割，从而加速每次迭代。

### 符号

| 符号 | 含义 |
|---|---|
| \(t\) | 阶段，\(t = 2, \dots, T\) |
| \(j\) | 场景节点索引，\(j = 1, \dots, M_t\) |
| \(k\) | 当前迭代轮次 |
| \(\mathcal{C}_{tj}^\ell(x_{t-1})\) | 第 \(\ell\) 条割在点 \(x_{t-1}\) 处的取值 |
| \(x_{t-1}^i\) | 第 \(i\) 轮前向传播得到的试探点 |
| \(I_{tj}^{ik}\) | 在第 \(i\) 个试探点处，到第 \(k\) 轮为止取值最大的割的索引集合（升序） |
| \(S_{tj}^k\) | 第 \(k\) 轮后实际选中的割索引集合 |
| \(m_{tj}^i\) | 第 \(i\) 个试探点处当前记录的最大割值 |
| \(r_{tj}^i\) | 第 \(i\) 个试探点处保留的“最旧最大割”的索引 |
| \(\epsilon_0\) | 数值容差，用于判断两个割值是否相等（通常取 \(10^{-6}\)） |

> **注意**：所有割的系数 \((\theta_{tj}^\ell, \beta_{tj}^\ell)\) 仍然全部存储，只是求解子问题时仅使用 \(S_{tj}^k\) 中的割构造近似函数：
> \[
> \Omega_t^k(x_{t-1}, \xi_{tj}) = \max_{\ell \in S_{tj}^k} \mathcal{C}_{tj}^\ell(x_{t-1}).
> \]

---

## 2. LML1 核心思想

对每个历史试探点 \(x_{t-1}^i\)：

1. 找出在该点处取值最大的所有割（可能有多条并列最大）。
2. 从这些割中，**只保留索引最小的那一条**（即生成最早、最旧的割）。
3. 将所有试探点保留的割取并集，作为当前实际使用的割集合 \(S_{tj}^k\)。

> **直观理解**：每个试探点只需要一条“代表割”，选最旧的，因为它在之前迭代中已被反复验证，稳定性最好。

---

## 3. 数据结构与初始化

### 3.1 存储结构

- 割列表：\(\mathcal{C}_{tj}^1, \mathcal{C}_{tj}^2, \dots\)，按生成顺序编号。
- 试探点列表：\(x_{t-1}^1, x_{t-1}^2, \dots\)。
- 对每个试探点 \(x_{t-1}^i\)，维护：
  - \(m_{tj}^i\)：当前最大割值；
  - \(r_{tj}^i\)：当前保留的最旧最大割索引。

### 3.2 初始化

- 第 0 轮：\(S_{tj}^0 = \emptyset\)（或按论文取 \(\{0\}\)，但实际从第 1 轮开始）。
- 第 1 轮：
  - 前向传播得到 \(x_{t-1}^1\)。
  - 后向传播生成割 \(\mathcal{C}_{tj}^1\)。
  - 对试探点 \(x_{t-1}^1\)：
    \[
    m_{tj}^1 = \mathcal{C}_{tj}^1(x_{t-1}^1), \quad r_{tj}^1 = 1.
    \]
  - 更新 \(S_{tj}^1 = \{1\}\)。

---

## 4. 每轮迭代的更新逻辑

在第 \(k\) 轮（\(k \ge 2\)）：

### 4.1 前向传播

得到新的试探点 \(x_{t-1}^k\)。

### 4.2 后向传播生成新割

计算新割 \(\mathcal{C}_{tj}^k\)，其系数为 \((\theta_{tj}^k, \beta_{tj}^k)\)。

### 4.3 处理新试探点 \(x_{t-1}^k\)

新割在生成它的试探点处满足：
\[
\mathcal{C}_{tj}^k(x_{t-1}^k) = \Omega_t(x_{t-1}^k, \xi_{tj}),
\]
这是该点处最紧的下界。因此直接初始化：
\[
m_{tj}^k = \mathcal{C}_{tj}^k(x_{t-1}^k), \quad r_{tj}^k = k.
\]

### 4.4 对每个历史试探点 \(x_{t-1}^i\)（\(i = 1, \dots, k-1\)）更新

计算新割在该点的值：
\[
v = \mathcal{C}_{tj}^k(x_{t-1}^i).
\]

与当前最大割值 \(m_{tj}^i\) 比较：

#### 情况 1：新割严格更大
若
\[
v > m_{tj}^i + \epsilon_0 \max(1, |m_{tj}^i|),
\]
则新割成为该点唯一最大割，更新：
\[
m_{tj}^i \leftarrow v, \quad r_{tj}^i \leftarrow k.
\]
（此时 \(k\) 是当前最大割中唯一的，也是最新的，但因为没有并列，所以它也是最旧的。）

#### 情况 2：新割与当前最大割并列
若
\[
|v - m_{tj}^i| \le \epsilon_0 \max(1, |m_{tj}^i|),
\]
则新割与旧的最大割在该点打平。由于新割的索引 \(k\) **大于**当前保留的索引 \(r_{tj}^i\)，LML1 要保留最旧的，因此**不替换**：
\[
m_{tj}^i \text{ 不变}, \quad r_{tj}^i \text{ 不变}.
\]

#### 情况 3：新割更小
若
\[
v < m_{tj}^i - \epsilon_0 \max(1, |m_{tj}^i|),
\]
则新割不是最大割，直接忽略。

### 4.5 更新选中割集合

所有试探点处理完毕后，得到：
\[
S_{tj}^k = \bigcup_{i=1}^k \{ r_{tj}^i \}.
\]

后续求解前向/后向子问题时，仅使用 \(S_{tj}^k\) 中的割构造近似函数。

---

## 5. 判断“最旧最大割”的逻辑总结

| 条件 | 动作 | 原因 |
|---|---|---|
| 新割严格更大 | \(r_{tj}^i \leftarrow k\) | 新割成为唯一最大，无并列 |
| 新割并列 | \(r_{tj}^i\) 不变 | 新割索引更大，保留更旧的 |
| 新割更小 | 忽略 | 不是最大割 |

由于割按生成顺序编号，索引越小 = 生成越早 = 越旧。因此：
- **严格更大**时，新割唯一最大，它就是最旧的（也是唯一的）。
- **并列**时，保留已有的旧索引，不替换。
- 最终 \(r_{tj}^i\) 始终是“在该点达到最大值的割中索引最小的那一个”。

---

## 6. 伪代码

```text
算法：LML1 割筛选（单阶段 t、单场景 j）

输入：
  历史试探点 x_{t-1}^1, ..., x_{t-1}^k
  历史割 C_{tj}^1, ..., C_{tj}^k
  容差 ε₀

输出：
  选中的割索引集合 S_{tj}^k

// 初始化第 k 轮新试探点
m_{tj}^k ← C_{tj}^k(x_{t-1}^k)
r_{tj}^k ← k

// 遍历历史试探点
for i = 1 to k-1 do
    v ← C_{tj}^k(x_{t-1}^i)
    if v > m_{tj}^i + ε₀ · max(1, |m_{tj}^i|) then
        // 新割严格更大
        m_{tj}^i ← v
        r_{tj}^i ← k
    else if |v - m_{tj}^i| ≤ ε₀ · max(1, |m_{tj}^i|) then
        // 并列，保留更旧的
        // r_{tj}^i 不变
    else
        // 新割更小，忽略
    end if
end for

// 收集所有试探点保留的割
S_{tj}^k ← ∅
for i = 1 to k do
    S_{tj}^k ← S_{tj}^k ∪ { r_{tj}^i }
end for

return S_{tj}^k
