# 负 gap 根因：θ 进了右端常数，没进约束矩阵

**结论（2026-10-10 实测）**：`code/subproblem.py` 的 `set_scene` 把
`F = rint(θ·n(x))` **算成一个数字写进约束右端**。右端对状态的依赖因此**不在 LP 的
系数矩阵里**，而 Benders 割的斜率取的是 `.dj`（既约成本）—— `.dj` 只反映状态作为
**变量界**的那一条通道。于是割的斜率**少了整整一项**

```
∂Q/∂n  =  .dj                （割用的）
       =  .dj + Σ_{r,a} ν_{r,a}·(∂F_{r,a}/∂x)     （真值，ν = ∂Q/∂F）
```

割的斜率偏移 ⇒ 割在锚点之外可以**高于**真值 ⇒ `V̂` 被顶高 ⇒ **LB 虚高 ⇒ 负 gap**。

**这与 `rint` 无关**：把 `F` 换成连续的 `θ·n` 后 LP 值函数对状态已经仿射、必然凸，
但割**照样越界**（`test/_cvx_rint.log` 的 `cont` 口径三个阶段全部 `★越界`）。

|---|---|---|---|---|

| 100 | (0,99) | −2,019.35 | 0.0272 | +1,819.35 |
| 200 | (0,76) | −0.50 | 0.0327 | −199.50 |

### 1.2 缺项的确切数值（`test/_cvx_fix.log`）

**模型完全没变（`Q` 逐位相同），变的只有对偶能看见的信息。**

## 2. 剩下的那一小截是 `rint` 的残差

系数口径下仍余的越界量**呈等幅锯齿**（阶段 199：`−51, −49, 0, −1, 1, −50, …`，
步长恒为 ~50）。这正是 `res = rint(θn) − θn ∈ [−0.5, 0.5]` 留在右端造成的：
残差对状态的依赖同样看不见，每格跳一次、幅度 `|ν|·|Δres| ≈ 100 × 0.5 = 50`。

**⇒ 只要保留 `rint`，右端就永远残留一个状态相关的阶梯，割就不可能严格合法。**
（振幅已由 ~2500 降到 ~500，是量级改善，但不是零。）

## 3. 修法（已实施）

**核心原则：状态对约束的一切依赖都必须走系数矩阵，右端不能出现「由状态算出来的数」。**

`docs/建模与实现.md` (4)(8) 记的 **Julia 原版就是这个原则**：`dem` / `trans` 的系数
是 `(1−θ)`（含 θ），不是把 `θ·n` 算成数字。Python 版把它挪成了右端常数。

**最终实现（`code/subproblem.py`）：`F` 是整数变量，由两条线性式夹出来。**

```
Fdef_hi: F[r,a] − θ_{r,a}·n_in[r,a] ≤ 0        F ∈ ℤ  ⇒  F = ⌊θ·n⌋
Fdef_lo: F[r,a] − θ_{r,a}·n_in[r,a] ≥ −1
dem_r  : Σ_m y[r,m] + Σ_a n_in[r,a] − Σ_a F[r,a] ≤ N_r
age_r,a: n_out[r,a+1] − n_in[r,a] + F[r,a] = 0
```

- 右端只有**纯结构常数** `0` / `−1`，没有任何状态导出的量；θ 以**系数**进矩阵
  ⇒ `.dj` 自动带回 `θν`（§1.2 用 `|ΔQ| = 0` + `.dj` 变化 `−53.88` 实证）。
- `F` 取整数（前向用整台失效数）；**615 个状态变量也全部声明 `INTEGER`** ——
  台数/件数物理上就是整数，且前向是 MILP、后向是它的 LP 松弛（标准
  SDDP-for-MILP 框架：松弛值 ≤ 整数最优 ⇒ 松弛对偶割是整数问题的合法下界）。
- LP 松弛下 `F ∈ [θn−1, θn]`，实测 `|F − θn| ≤ 1.000`，与连续口径同量级。

**走不通的两条路（都已实测排除）：**

| 写法 | 结果 |
|---|---|
| 把 `F` 建成变量，但用**变量界**钉成 `rint(θn̄)` | `Q` 与 `.dj` 与现状**逐位相同** ⇒ 等于把数字换地方写 |
| 保留 `rint`（`F − θ·n = res`，残差进右端） | 残差本身是状态导出的右端常数 ⇒ 锯齿重现，阶段 100/199 仍越界 −525/−51 |

## 4. 改完之后的验收（2026-10-10）

| 项 | 结果 |
|---|---|
| 冒烟 60 轮 gap（T=4） | **+0.2269%**（正）；对照：旧口径生产 −5.10%、连续 F 冒烟 −0.10% |
| `test/_t_nint.py` | 615/615 状态为 `I`；前向路径离整距离恒 **0.000000** |
| `test/_t_cutvalid.py`（219 个 (割,点)，**跨小数点**扫） | ①算法性质 **越界 0 个**，最小余量 −0.0009（|Q|~3e6–9e6 ⇒ 1e-10，LP 容差）；②存盘割与全池对拍差 **0.0** |
| LP 松弛下 F 与 θn 的偏差 | ≤ **1.000**（F ∈ [θn−1, θn]） |

**代价**：615 个状态声明 INTEGER 让前向 MIP 慢约 3×（冒烟 60 轮：训练 4.1 s → 13.0 s，
整跑 8.1 s → 61.0 s）。这个声明在数值上是冗余的（`n_out = n_in − F` + `y` 整数已
自动保整），但按用户口径**前向必须显式声明整数、后向才是它的松弛**，故保留。
