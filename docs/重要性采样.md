# 重要性采样（Importance Sampling）算法说明

> 面向 SDDP / 多阶段随机规划的上界方差控制。核心思想：**有偏采样 + 似然比修正**，在保持无偏估计的同时显著降低上界波动。

---

## 1. 问题背景

在 SDDP 中，上界通常由前向过程模拟策略得到：

\[
\bar V=\frac{1}{K}\sum_{k=1}^K u^k,\quad u^k=\text{第 }k\text{ 条路径的总成本}
\]

当场景方差大、极端场景稀少时，标准 Monte Carlo（MC）均匀采样的上界估计抖动严重，停止准则难以判断。

**重要性采样（IS）** 的目标：用同样的样本量，得到方差更小的无偏上界估计。

---

## 2. 基本思想

标准 MC 从原始分布 \(f(\xi)\) 采样。IS 改为从**另一个分布** \(g(\xi)\) 采样，并对每个样本乘以**似然比**修正偏差：

\[
\lambda(\xi)=\frac{f(\xi)}{g(\xi)}
\]

估计量：

\[
\overline{v}_{\text{IS}}=\frac{1}{K}\sum_{k=1}^K v(\xi^k)\cdot\lambda(\xi^k),\quad \xi^k\sim g
\]

**无偏性**：

\[
\mathbb E_g\big[v(\xi)\lambda(\xi)\big]
=\int v(\xi)\frac{f(\xi)}{g(\xi)}g(\xi)\,d\xi
=\int v(\xi)f(\xi)\,d\xi
=\mathbb E_f[v(\xi)]
\]

**直观**：在 \(g\) 下更容易抽到的场景，\(\lambda\) 小，权重被压低；在 \(g\) 下不容易抽到、但在 \(f\) 下重要的场景，\(\lambda\) 大，权重被放大。总体上期望不变。

---

## 3. 理想分布：零方差

令 \(v(\xi)\) 为场景成本。理论上最优的采样分布为

\[
g^*(\xi)\propto |v(\xi)|\cdot f(\xi)
\]

此时每个样本修正后都相等：

\[
v(\xi)\lambda(\xi)=v(\xi)\frac{f(\xi)}{g^*(\xi)}=\text{常数}
\]

方差为零。**实践中的全部工作，就是用一个可计算的近似 \(\hat v(\xi)\) 去逼近这个 \(g^*\)。**

---

## 4. 具体例子：300 个等概率场景

设某阶段有 300 个等概率场景（\(f_j=1/300\)）：

- 3 个极端场景：成本 \(v=1000\)；
- 297 个正常场景：成本 \(v=100\)。

真实期望：

\[
E[v]=\frac{3\times1000+297\times100}{300}=109
\]

标准 MC 的方差约 \(8019\)，标准差约 \(89.5\)。

构造 \(g_j\propto |v_j|f_j\)：

- 极端场景权重 \(1000/300\approx3.333\)
- 正常场景权重 \(100/300\approx0.333\)

归一化（总权重 \(3\times3.333+297\times0.333\approx109\)）：

\[
g(\text{极端})=\frac{3.333}{109}\approx0.03058,\quad
g(\text{正常})=\frac{0.333}{109}\approx0.003058
\]

似然比：

\[
\lambda(\text{极端})=\frac{1/300}{0.03058}\approx0.109,\quad
\lambda(\text{正常})=\frac{1/300}{0.003058}\approx1.09
\]

修正后样本值：

- 极端：\(1000\times0.109=109\)
- 正常：\(100\times1.09=109\)

**每个样本修正后都等于 109，方差为零。**

## 5. 在 SDDP 中怎么用

### 5.1 用在哪里

| 用途 | 位置 | 效果 |
|---|---|---|
| **上界估计** | 前向过程 | 最常用，直接压低上界波动 |
| 下界/割生成 | 后向过程 | 较少用，可加速收敛或做风险导向采样 |

### 5.2 实施步骤（前向上界）

1. **估计近似成本** \(\hat v_j\)：用当前近似价值函数或一个粗略策略，对每个场景 \(j\) 算一个近似总成本。
2. **构造采样分布**：
   \[
   g_j=\frac{|\hat v_j|\,f_j}{\sum_{i=1}^{M}|\hat v_i|\,f_i}
   \]
   加数值保护：\(g_j\ge \epsilon f_j\)，防止 \(\lambda\) 爆炸。
3. **从 \(g\) 采样**：前向过程按 \(g_j\) 抽场景，而不是均匀抽。
4. **似然比修正**：
   \[
   \lambda_j=\frac{f_j}{g_j},\quad
   \bar V_{\text{IS}}=\frac{1}{K}\sum_{k=1}^K u^k\lambda(\xi^k)
   \]
5. **构造置信区间**：在固定 \(g\) 下采 \(K\) 条路径，用样本均值和标准差：
   \[
   \bar V_{\text{IS}}\pm z_{\alpha/2}\frac{\hat\sigma_{\text{IS}}}{\sqrt K}
   \]

### 5.3 伪代码

```text
输入: 场景集 {ξ_j, f_j}_{j=1..M}, 近似价值函数 V̂, 样本数 K
输出: 重要性采样上界 V̄_IS 及其置信区间

1. 对每个场景 j:
       v̂_j ← 用 V̂ 模拟策略得到近似成本
2. 构造采样分布:
       w_j ← |v̂_j| * f_j
       g_j ← w_j / sum(w)
       g_j ← max(g_j, ε * f_j)        # 数值保护
       g_j ← g_j / sum(g)             # 重新归一化
3. 对 k = 1..K:
       ξ^k ~ g
       u^k ← 按策略模拟该路径的总成本
       λ^k ← f(ξ^k) / g(ξ^k)
       y^k ← u^k * λ^k
4. 计算:
       V̄_IS ← mean(y^1..y^K)
       σ̂_IS ← std(y^1..y^K)
       CI ← V̄_IS ± z_{α/2} * σ̂_IS / sqrt(K)
5. 返回 V̄_IS, CI
```

## 6. 似然比会随训练变化吗？

**会，取决于 \(g\) 是否更新。**

### 6.1 \(g\) 固定

训练早期构造一次 \(g\)，之后全程使用。

- \(\lambda_j=f_j/g_j\) 是**固定常数向量**；
- 实现简单，停止准则统计量可比；
- 缺点：早期 \(\hat v\) 差，\(g\) 可能逐渐偏离最优。

### 6.2 \(g\) 随近似价值函数更新

每隔若干轮用最新 \(\hat v\) 重构 \(g\)。

- \(\lambda\) 随之变化；
- 每轮内部仍无偏，但跨轮样本不能混在一起算方差；
- 建议**周期性更新**，并在固定 \(g\) 下采一批评估样本做上界统计。

### 6.3 数值保护

\[
g_j\ge \epsilon f_j \quad\Rightarrow\quad \lambda_j=\frac{f_j}{g_j}\le\frac{1}{\epsilon}
\]

防止某个场景在 \(g\) 下概率过小导致单个样本权重爆炸。

---

## 7. 与 QMC / LHS 的关系

| 方法 | 是否保持 i.i.d. | 是否改变采样分布 | 主要作用 |
|---|---|---|---|
| 标准 MC | 是 | 否 | 基线 |
| **IS** | 是（在 \(g\) 下） | 是 | **降方差，尤其高方差问题** |
| QMC | 否 | 否 | 低维均匀性更好，但破坏独立性 |
| LHS | 否 | 否 | 分层采样，需分块保持收敛性 |

IS 的优势：**保持 i.i.d.**，收敛理论直接适用；缺点是需构造 \(g\)。

---

## 8. 注意事项

1. **无偏性只在单轮内成立**：跨轮混样本会破坏置信区间。
2. **\(g\) 更新频率**：太频繁上界不可比，太慢 \(g\) 质量下降。折中：周期性更新。
3. **\(\lambda\) 上界保护**：必须设 \(g_j\ge\epsilon f_j\)。
4. **近似成本 \(\hat v\) 的质量**：越接近真实 \(v\)，方差越小；但即使粗糙近似，只要方向对，通常也能显著降方差。
5. **后向过程慎用**：后向用 IS 会改变割的统计性质，需单独分析无偏性。

---

## 9. 本项目落地口径（2026-11-06）

- 只用于**训练前向**：前 `build_after_round` 轮（配置，默认 50）均匀采样；随后用这些轮次累积的路径，对每个场景估计一个**全局分数**（包含该场景的路径平均总成本），所有阶段共用一个 proposal；
- 构造 `g_j = uniform_floor/M + (1-uniform_floor)·score_norm_j`，`uniform_floor` 默认 0.05；不做阶段窗口、经验贝叶斯收缩、MAD 或权重裁剪；
- proposal 构建一次后固定；训练前向按 g 采样，路径权重为 \(\prod_t (1/M)/g_{j_t}\)，训练 `sim` 使用加权均值；
- 仿真（`simulate.py`）仍使用**均匀 MC**，不使用 IS；因此最终 UB/CI 是标准 MC 口径；
- proposal 必须对所有场景正概率（`uniform_floor>0`）；否则 \(f/g\) 无定义或估计有偏。权重不做 clipping；
- 训练前向与后向共用现有 RNG；IS 激活后后向随机流也会变化，A/B 不逐位复现；
- 报告 proposal 指纹、权重 min/median/max、ESS；若 ESS 过低，说明 IS 未改善，不能据此反复调 proposal 再看最终结果。

## 10. 一句话总结

**重要性采样 = 按 \(|v|f\) 有偏采样 + 似然比 \(f/g\) 修正。** 它不改变原问题，只改变“抽样从哪来”；理想分布 \(g^*\propto|v|f\) 使方差趋零，实践中用近似价值函数构造 \(g\)，在保持无偏的同时显著压低 SDDP 上界波动。
